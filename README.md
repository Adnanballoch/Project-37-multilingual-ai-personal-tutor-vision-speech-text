# Project 37: Multilingual AI Personal Tutor: Vision + Speech + Text

**Category:** EdTech
**Part of:** AutoMatrixLab

## Overview

A multilingual personal tutor that can see what is on the page or screen, listen to questions, speak clear explanations, and write step-by-step answers on demand.

## Tech Stack

Local LLM, NVIDIA RTX 4070 Super, Ollama, TTS/STT, Vision AI
